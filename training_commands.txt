  主程序模型说明 & 训练指南
  项目: 膳食健康助手 (Dietary Health Assistant)
  模型: YOLOv8l-cls (YOLOv8 Large Classification)
  数据集: Food-101 (101 类)

【模型在推理中的位置】

  用户拍照 → Flask 接收 → YOLOv8l 识别食物名 → 营养库查询 → 返回前端
                                    ↓
                          DeepSeek 联网百科增强

  模型文件: runs/classify/food_cls_l/weights/best.pt
  加载方式: torch.load() → ckpt['model'] (导出时已剥离 LoRA，可直接推理)

【模型输入 (Input)】

  图像大小:   224 × 224 像素
  预处理流程:
    1. cv2.imread() 读取图片 (BGR)
    2. cv2.cvtColor(BGR → RGB)
    3. PIL.Image.fromarray() 转为 PIL 图像
    4. transforms.Resize(224)        ← 等比缩放，短边 224
    5. transforms.CenterCrop(224)    ← 中心裁剪 224×224
    6. transforms.ToTensor()         ← 转为 [0,1] 范围的张量
    7. transforms.Normalize(
         mean=[0.485, 0.456, 0.406],  ← ImageNet 均值
         std=[0.229, 0.224, 0.225]    ← ImageNet 标准差
       )

  推理增强 (提高低质量图片识别率):
    - cv2 锐化 (kernel_size=3, alpha=0.5)
    - CLAHE 对比度增强

【模型输出 (Output)】

  softmax 后: probs.shape = (1, 101)   ← 概率分布

① LoRA+ 训练 (当前主程序使用的训练策略)
───────────────────────────────────────────────────────────────
  特点: 只训练低秩适配器 + 分类头，冻结主干网络
        参数量小、训练快、显存需求低
        导出时自动合并权重为标准 checkpoint，推理无额外开销

  python train_yolo.py \
    --strategy lora_plus \
    --data datasets/food_cls \
    --model yolov8l-cls.pt \
    --epochs 100 \
    --batch 64 \
    --workers 4 \
    --prefetch-factor 8 \
    --lr0 0.001 \
    --lora-rank 8 \
    --lora-alpha 16 \
    --lora-plus-ratio 16 \
    --aug-strength medium \
    --patience 30 \
    --name food_cls_lora

  关键参数说明:
    --lora-rank 8         LoRA 低秩矩阵的秩 (越大越接近全量微调)
    --lora-alpha 16       LoRA 缩放系数 (控制适配器更新强度)
    --lora-plus-ratio 16  上投影学习率 = lr0 × ratio (LoRA+ 核心)
    --lr0 0.001           基础学习率 (推荐 0.0005~0.001)
    --batch 64            批大小 (显存不够就减小)
    --patience 30         早停耐心值 (30轮不提升则停止)
    --aug-strength medium 数据增强强度 (weak/medium/strong)
    --label-smoothing 0.0 标签平滑 (防过拟合，推荐 0.05~0.1)
    --subset 1.0          训练数据比例 (0.1 = 只用10%，快速验证用)

  输出文件:
    runs/classify/<name>/weights/best.pt     ← 最佳模型 (推理用这个)
    runs/classify/<name>/weights/last.pt     ← 最后一轮的模型
    runs/classify/<name>/history.csv         ← 训练指标 CSV
    runs/classify/<name>/history.json        ← 训练指标 JSON
    runs/classify/<name>/training_curves.png ← 损失 & 准确率曲线
    runs/classify/<name>/lora_training_state.pt ← 断点恢复文件

② 全量微调 (追求最高精度)
───────────────────────────────────────────────────────────────
  特点: 所有参数都参与训练
        精度最高，但显存需求大、训练慢

  python train_yolo.py \
    --strategy full \
    --data datasets/food_cls \
    --model yolov8l-cls.pt \
    --epochs 100 \
    --batch 32 \
    --workers 4 \
    --lr0 0.001 \
    --aug-strength medium \
    --patience 20 \
    --name food_cls_full

  预期精度: Val Acc ≈ 88-92%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

③ 分阶段微调 (冻结 → 解冻)
───────────────────────────────────────────────────────────────
  特点: 先冻结主干训练分类头，再解冻全量训练
        比全量微调略快，精度接近

  python train_yolo.py \
    --strategy freeze_then_unfreeze \
    --data datasets/food_cls \
    --model yolov8l-cls.pt \
    --freeze-epochs 20 \
    --unfreeze-epochs 30 \
    --freeze-layers 10 \
    --batch 64 \
    --workers 4 \
    --lr0 0.001 \
    --name food_cls_staged

───────────────────────────────────────────────────────────────

    --resume \
    --batch 64 \
    --workers 4 \
    --prefetch-factor 8 \

    --epochs 120 \

【训练完后如何部署到主程序】

  1. 训练完成，确认 runs/classify/<name>/weights/best.pt 存在
  2. 修改 food_detection_service.py 中的模型路径:
     model_name = 'runs/classify/<name>/weights/best.pt'
  3. 重启 Flask 服务即可

  或者直接覆盖现有模型文件:
  cp runs/classify/<name>/weights/best.pt runs/classify/food_cls_l/weights/best.pt
